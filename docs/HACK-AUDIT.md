# Hack audit: what the bring-up tree carried, and what this overlay keeps

The overlay was generated by diffing pristine `sm8450-mainline/linux` @ `bf1d29fc` against
the bring-up tree (last flashed as bring-up image v89, 2026-09-26), then cleaning each change.
`kernel/regen-patches.sh` repeats the diff and reports any changed file no patch covers.

## Dropped

| What | Why |
|---|---|
| `drivers/pinctrl/core.c`, `pinctrl-msm.c` boot traces | early-boot hang hunting (the TrustZone-owned GPIO hang, fixed by `gpio-reserved-ranges`) |
| `INTERCONNECT_ALLOW_WRITE_DEBUGFS` | debugging aid, upstream keeps it off on purpose |
| `lpm-dbg` prints in the LPASS runtime-PM callbacks | temporary, used to prove the macros suspend |
| hung-task / lockup detectors, DRM panic screen, fonts | moved to the opt-in `kernel/config/x700-debug.config` |
| Lab-notebook comments (version-numbered history in the DTS and charger drivers) | replaced by one comment per non-obvious property stating the hardware reason; the charging design is summarised in `CHARGING.md` |

## Kernel command line (`/chosen/bootargs`)

uniLoader passes none, so it lives in the DTS. Final:

```
console=tty0 quiet loglevel=4 panic=10 plymouth.enable=0 arm-smmu.disable_bypass=0
usbcore.autosuspend=-1 pmos_rootfsopts=defaults
```

| Kept | Why |
|---|---|
| `arm-smmu.disable_bypass=0` | the bootloader leaves the display scanout behind the SMMU |
| `usbcore.autosuspend=-1` | USB host autosuspend hung the SoC |
| `plymouth.enable=0` | plymouth and fbcon fought over one framebuffer |

| Removed | Note |
|---|---|
| `clk_ignore_unused pd_ignore_unused` | not needed since the native display driver; boots without them since image v83 |
| `oops=panic panic=0 nokaslr hung_task_timeout_secs=2 watchdog_thresh=1 drm.panic_screen=kmsg` | hang diagnosis; see `INSTALL.md` "Debugging" to add them back per build |
| `earlycon=... loglevel=7 ignore_loglevel systemd.show_status=1 log_buf_len=4M systemd.log_*` | verbose console |
| `PMOS_NO_OUTPUT_REDIRECT` | initramfs debugging |
| `pmos_boot_uuid= pmos_root_uuid=` | one unit's install; the initramfs finds `pmOS_boot`/`pmOS_root` by label. `build-boot-img.sh --append-bootargs` pins them if wanted |

## Found while cleaning

- The touchscreen driver (`CONFIG_TOUCHSCREEN_NOVATEK_NVT_TS`) was never in the bring-up
  config: touch worked only because a module built in an earlier session stayed in the
  rootfs. `x700.config` now sets it `=m`. Rebuilding the rootfs modules from a clean config
  is what exposed it; do that whenever the config changes.

## Kept on purpose (do not "simplify")

- **Sensor rails.** pm8350c L2C is declared without always-on/boot-on and switched by the
  `sensor-vdd` regulator-output node from userspace (`sensor-vdd.service`); declaring it
  always-on hangs the boot. L13C stays undeclared: it is also the panel's `vci-supply`.
- **Panel buck always-on**: the NT36523 panel driver takes one supply.
- **`vreg_l7e_2p8` always-on**: Wi-Fi antenna switch, nothing in mainline consumes it.
- **Samsung reserved-memory nodes**: taken from the live Android FDT of a revision-8 board.
- **Wi-Fi sleep hook** (`50-wcn6855-wifi`): WCN6855 with Samsung's firmware comes back from
  any suspend in MHI SYS_ERR, so ath11k is unloaded before sleep and reloaded after. The
  in-kernel fix is ath11k power-down-on-suspend for this platform. Never `rmmod ath11k_pci`
  on an already wedged chip: that hard-hangs the SoC; the hook checks for that.

## Status (2026-09-26)

Verified on hardware: the overlay kernel (from `kernel/build.sh` and from the pmOS package,
identical DTB and config), a from-scratch `pmbootstrap install` with Plasma flashed to
USERDATA, and `gts8wifi-firmware-setup` run on the device (GPU, audio and sensor DSPs,
5 GHz Wi-Fi, sensor registry). Found and fixed along the way: the touch driver missing from
the config, zram without zstd, two direct-charging latch bugs, `vendor` spanning two extents
of `super`, Samsung's compressed F2FS on `vendor`, the on-screen keyboard not selected in KWin.

## Open

- Kernel updates through `apk` land in `/boot` but not in the BOOT partition; the boot image
  has to be rebuilt on a PC (`boot/build-from-pmos.sh`). uniLoader is not built on-device yet.
- Sleep drain is ~140 mA in s2idle although CX collapse is reached; remaining suspects are
  board rails (S Pen AVDD, panel buck, L7E, BT) and AOSS/DDR sleep.
- Microphones record silence; camera, gyroscope, keyboard cover not supported.
- Drivers without DT bindings yet: wacom-wez01, ps5169, the two charger drivers.
